How it works & the agent prompt

Ears

The browser's Web Speech API turns your voice into text. Hands-free mode reopens the mic each time the tutor finishes talking. It works in Chrome and Edge.

Brain

A built-in tutor with 75 words across three levels picks words, asks quiz questions, checks your answers, and reviews earlier words. Everything runs in your browser: no account, no data sent anywhere. The prompt below is the AI version of the same tutor, for use with Claude.

Voice

The browser's speech synthesis reads each reply aloud. You can change the voice and speed, or mute it.
